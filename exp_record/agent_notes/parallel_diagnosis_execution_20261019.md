## Video and attribution contract

At each displayed executed interval, show: task/subgoal, the **pre-action** measured
evidence, trigger/check results and unknowns, model-generated proposal source,
selected action and current owner, budget use, then separately the measured
**post-action** result. Show local revalidation and actual handoff as separate events;
an exit condition alone must not be drawn as a completed handoff. A trace cannot
use later success to invent an earlier justification.

For mechanism comparisons: baseline VLA left / actual framework right, common
simulation clock and initial state, intervention/phase/source/timing labels, explicit
held end frames. Simple-feedback arm gets its own matched comparison. For camera
diagnosis: original view left / framed view right, clearly actor-only, gate/repair
inactive. Every control action remains the logged unmodified model proposal.
Rendering overlays from contemporaneously recorded trace fields is synchronized
review, not a claim of a live wall-clock dashboard or internal model chain-of-thought.

Once completed, retain all failures and all arms, publish videos and complete source/
state/image/action evidence, independently replay and verify GitHub/LFS recovery.
